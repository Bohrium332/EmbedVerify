# AI Context

This folder is the handoff package for AI agents and engineers working on this
repository. It is intentionally separate from product/user documentation so the
project state, architecture decisions, and active implementation rules are easy
to find.

Read these files before changing code:

1. `PROJECT.md` - project purpose and MVP scope
2. `ARCHITECTURE.md` - framework layers and responsibilities
3. `CONVENTIONS.md` - hard implementation rules
4. `PROGRESS.md` - completed work and upcoming work
5. `HANDOFF.md` - latest board verification state
6. `DECISIONS.md` - agreed architecture decisions

Every execution turn must end with:

```text
本轮完成：
下一轮待办：
下下轮待办：
```
